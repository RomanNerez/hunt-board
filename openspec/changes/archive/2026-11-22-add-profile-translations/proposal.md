# Proposal

## Why

Профіль у Hunt Board — це дані для резюме й відгуків на вакансії. Вакансії бувають українськими й англійськими, тож тексти профілю (заголовок, «Про себе», освіта тощо) потрібні двома мовами. Зараз кожне поле зберігає лише одне значення, і англійську версію ніде тримати.

## What Changes

- Текстові поля профілю зберігаються двома мовами: українською (основна, як зараз) та англійською.
- Перекладні поля:
  - «Загальне»: «Ім'я», «Прізвище», «Локація», «Заголовок», «Про себе»;
  - «Освіта»: «Назва», «Заклад / організація», «Опис»;
  - «Мови»: «Мова», «Опис»;
  - «Навички»: «Назва групи»;
  - «Посилання»: «Назва», «URL» (наприклад, окремі мовні версії профілю LinkedIn).
- Спільні для обох мов поля (без перекладу): email, телефон, URL освіти, тип освіти, дати, рівень мови, технології групи навичок, порядок записів.
- На кожній сторінці розділу «Профіль» у шапці з'являється перемикач мови даних «Українська / English». За замовчуванням активна українська. Перемикач показує перекладні поля вибраної мови. Спільні поля й набір записів у списках однакові для обох мов.
- Одна кнопка «Зберегти» зберігає обидві мови одночасно.
- Обов'язковість полів діє лише для української. Англійські значення необов'язкові, а обмеження довжини для них ті самі.
- Перекладні колонки оголошуються як `jsonb` прямо в наявних міграціях профілю. Профіль ще не в продакшені, тож перенесення даних не потрібне.
- Нова Composer-залежність `spatie/laravel-translatable` ^6 у контейнері Profile.

**Не входить у зміну:**
- Мова інтерфейсу панелі: підписи, меню, повідомлення лишаються українськими, перемикача мови інтерфейсу немає.
- Переклад даних поза профілем (компанії, статуси, типи компаній, домени).
- Автоматичний переклад, генерація чи експорт резюме певною мовою.
- Інші мови, крім української та англійської.

## Capabilities

### New Capabilities
- `profile-translations`: двомовне зберігання й редагування текстових полів профілю: перелік перекладних і спільних полів, перемикач мови на сторінках профілю, правила валідації для кожної мови.

## Impact

- Контейнер `app/Containers/AppSection/Profile`: моделі `UserProfile`, `ProfileEducation`, `ProfileLanguage`, `ProfileSkillGroup`, `ProfileLink`; Tasks `Upsert*`/`Replace*`; Filament-сторінки `ProfileFormPage` і `EditProfile*`; фабрики, `composer.json` контейнера, наявні міграції, тести.
- БД: перекладні колонки таблиць `user_profiles`, `profile_educations`, `profile_languages`, `profile_skill_groups`, `profile_links` стають `jsonb` (`{"uk": "...", "en": "..."}`). Змінюються наявні міграції `2026_11_22_100000`…`100005`, нової міграції немає.
- Залежності: `spatie/laravel-translatable` ^6 (погоджено користувачем). Інших контейнерів зміна не зачіпає.
